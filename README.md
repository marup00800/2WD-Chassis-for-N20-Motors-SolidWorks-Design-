# 2WD Robot Chassis for N20 Motors – SolidWorks Design

This project features a custom-designed **2WD robot chassis**, modeled in **SolidWorks**, optimized for **N20 micro DC geared motors**.  
The chassis is lightweight, compact, and ideal for robotics projects such as line-following robots, smart cars, or indoor navigation bots.

## 🔩 Features
- Designed for **N20 micro DC motors**  
- **Mounting slots** for N20 motor brackets and wheels  

## 🧠 Tools Used
- SolidWorks
